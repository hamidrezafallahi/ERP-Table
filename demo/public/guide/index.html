Install a Persian data grid in React

persian-data-grid is an ERP Data Grid: RTL, Jalali date cells, Excel-like keyboard, virtual scroll, and Excel/PDF plugins.

Install

npm i persian-data-grid

Peer dependencies: react and react-dom (^17 / ^18 / ^19).

Quick start

import { ERPTable } from 'persian-data-grid';

<ERPTable
  store="erp"
  tableKey={pageId}
  actor={actor}
  columns={columns}
  rows={rows}
  tableHeight={420}
  multiSelectConfig={multiSelectConfig}
  onReady={setController}
/>

Headless composition

import { createERPTable, VirtualList } from 'persian-data-grid';

const grid = await createERPTable({
  store: 'erp',
  tableKey: 'voucher-1',
  actor: { userId: 'u1', roles: ['admin'] },
  columns,
  rows,
});

What you get

  • Grid — rows, pagination, row actions
  • Excel keyboard — arrows / Tab / Enter between cells
  • VirtualList — visible rows only
  • Plugins — requestExport({ format: 'xlsx' | 'pdf' })
