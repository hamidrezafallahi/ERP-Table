# Internationalization

Locale packs: `fa` (default), `en`, `ar`. Control `direction` and `numberingSystem`, or let them follow the locale.

<LiveDemo name="i18n" />

```tsx
import { DataGrid, EN_MESSAGES } from 'persian-data-grid';

<DataGrid
  locale="en"
  messages={EN_MESSAGES}
  direction="ltr"
  numberingSystem="latn"
  rowData={rows}
  columnDefs={cols}
/>
```

Subpaths: `persian-data-grid/locales/fa|en|ar`.
