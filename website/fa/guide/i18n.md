# چندزبانه

بسته‌های `fa` (پیش‌فرض)، `en`، `ar`. `direction` و `numberingSystem` را صریح بدهید یا از locale پیروی کنید.

<LiveDemo name="i18n" />

```tsx
import { DataGrid, EN_MESSAGES } from 'persian-data-grid';

<DataGrid
  locale="en"
  messages={EN_MESSAGES}
  direction="ltr"
  numberingSystem="latn"
  rowData={rows}
  columnDefs={cols}
/>
```

Subpath: `persian-data-grid/locales/fa|en|ar`.
