Bootstrap

 bootstrap فقط wiring انجام دهد، هیچ rule یا تصمیم دامنه‌ای داخلش نباشد

 buildTable فقط factory باشد، نه محل business logic (computed/visibility را بعداً قابل جابجایی نگه دار)

 policyها فقط تزریق شوند، نه ساخته‌شدن شرطی داخل bootstrap

 RemoteApi / Repo / Audit کاملاً قابل تعویض باشند

 bootstrap هیچ وابستگی به React یا UI نداشته باشد

Engine

 Engine فقط coordinator باشد (dispatch + state sync)

 Engine مستقیماً ViewModel نسازد (حداقل‌سازی getViewState)

 state دامنه‌ای (Table) و state نمایشی (expanded) مرزبندی شده باشند

 Engine repository را برای read مستقیم دور نزند (یا نتیجهٔ app را بگیرد یا event مصرف کند)

 expand به‌عنوان UI intent دیده شود، نه business rule

UITableController

 Controller فقط translate کند (UI event → command)

 هیچ state نگه ندارد

 keybinding فقط اینجا باشد، نه Engine

 toggle/expand اگر domain-impact دارد → command؛ اگر ندارد → UI intent

UI Layer

 UI فقط subscriber باشد

 hook فقط bridge باشد، نه محل logic

 هیچ domain object مستقیم mutate نشود

 ERPTable فقط composition انجام دهد

Adapters (Infra / UI)

 Infra کاملاً framework-agnostic بماند

 UI Adapter به Engine وابسته باشد، نه Domain

 هیچ type مربوط به React داخل Engine یا Domain نماند

General ERP Sanity Checks

 multi-table همزمان بدون تداخل state

 refresh داده backend بدون از دست‌دادن UI intent

 امکان headless consumption (بدون React)

 امکان تست Engine بدون UI
