# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 0.5.x (latest npm) | Yes |
| 0.6.x (unreleased) | Yes, once published |
| 0.4.x and earlier | No |

## Reporting a vulnerability

Please use GitHub’s **Privately report a vulnerability** flow:

https://github.com/hamidrezafallahi/ERP-Table/security/advisories/new

Do **not** file a public issue for a security report.

Include a description, impact, and reproduction steps if you have them. We aim to acknowledge within 7 days.
